# **App Name**: Penaca Circular

## Core Features:

- Hero Section: A visually appealing section that introduces Penaca Circular Solutions and its mission, using gradients, animated elements, and clear CTAs.
- Statistics Display: Display key metrics and achievements related to Penaca Circular Solutions' impact using animated counters, visually engaging icons, and descriptive labels.
- Process Visualization: Showcase Penaca Circular Solutions' recycling process in a clear and interactive manner using connecting lines, step-by-step descriptions, and engaging icons.
- Product Showcase: Enable users to explore Penaca Circular Solutions' premium recycled materials using tabbed navigation, detailed product descriptions, application examples, and specification tables.
- Contact Form with data storage: Allow potential customers to submit their questions using contact forms, where submissions are saved in the Firestore database.

## Style Guidelines:

- Primary color: Main Green (#22c55e) to convey sustainability and environmental friendliness.
- Accent color: Deep Purple (#40196C) for premium and sophisticated touch.
- Neutral colors: Range from Neutral-900 (#0f172a) to Neutral-50 (#f8fafc) for creating balanced contrast and clean design.
- Headings: 'Poppins', sans-serif, for a modern and readable style.
- Body Text: 'Inter', sans-serif, to maintain simplicity and readability for main content.
- Accents/Stats: 'Montserrat', sans-serif to highlight important accents and statistic.
- Micro interactions (hover): 0.2-0.3s, ease in out function
- Key Animation Types: Counter Animation and scroll reveal patterns to provide engage users as they navigate the webpage.
